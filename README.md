# Бесплатные находки для Etsy/eBay → Telegram

4 раза в день (8:07, 12:07, 16:07, 20:07 по Софии зимой) робот на GitHub Actions:
1. берёт новые бесплатные объявления с **OLX.bg** («Подарявам»), **Bazar.bg** (фильтр «Подарявам») и **Alo.bg** (поиск «подарявам»/«подаряваме»);
2. отсеивает очевидный мусор по словам (котята, диваны, дрова…);
3. показывает фото и текст нейросети **Gemini** и спрашивает: можно ли это продать на Etsy/eBay;
4. всё с оценкой 6/10 и выше присылает тебе в **Telegram** — фото, что нашлось, примерная цена, город, ссылка.

Всё бесплатно: приватный репозиторий GitHub (≈300 из 2000 бесплатных минут в месяц), бесплатный ключ Gemini, Telegram.

---

## Настройка (≈15 минут)

### 1. Telegram-бот
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. Скопируй **токен** (вида `123456:ABC...`).
3. Открой своего нового бота и отправь ему любое сообщение, например «привет».

### 2. Ключ Gemini
1. Зайди на **aistudio.google.com** → **Get API key** → **Create API key**.
2. Скопируй ключ (начинается с `AIza...`). Карта не нужна.

### 3. Репозиторий на GitHub
1. **github.com → New repository** → имя `olx-free-finder` → **Private** → Create.
2. На странице репозитория: **Add file → Upload files** → перетащи **всё содержимое** распакованного архива (папки `.github`, `finder`, `state`, `tests` и файлы). Папка `.github` скрытая — если Windows её не показывает, включи «Показывать скрытые элементы» в Проводнике. → **Commit changes**.

### 4. Секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**, создай:

| Name | Value |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather |
| `GEMINI_API_KEY` | ключ из AI Studio |
| `TELEGRAM_CHAT_ID` | пока поставь `0`, ниже узнаем настоящий |

### 5. Узнать chat ID и проверить
1. **Actions** → слева **Free stuff finder** → **Run workflow** → mode: **chat-id** → Run.
2. Открой запуск → шаг **Run** → там строка `TELEGRAM_CHAT_ID = 123456789`.
3. Обнови секрет `TELEGRAM_CHAT_ID` этим числом.
4. **Run workflow** → mode: **test** → в Telegram должно прийти «✅ Бот работает».
5. **Run workflow** → mode: **run** — первый настоящий поиск.

> Первый запуск анализирует ~60 самых свежих объявлений, а остальные помечает как просмотренные — дальше приходят только новые.

Готово. Дальше всё работает само.

## Настройки (необязательно)
**Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**:

| Variable | По умолчанию | Что делает |
|---|---|---|
| `MIN_SCORE` | `6` | порог оценки ИИ (0–10). Много мусора → `7`, мало находок → `5` |
| `MAX_AI_PER_RUN` | `60` | сколько объявлений максимум отдавать ИИ за запуск |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | модель Gemini (бесплатно: 15 запросов/мин, 500/день; лимиты моделей — AI Studio → Rate Limit) |

Список слов-«мусора» — в `finder/prefilter.py`. Текст задания для ИИ — в `finder/ai.py` (`PROMPT`).

Расписание — в `.github/workflows/finder.yml`, строка `cron` (время в UTC: София = UTC+2 зимой, UTC+3 летом).

## Если что-то не работает
- **Actions → последний запуск → шаг Run** — там лог: сколько объявлений собрано с каждого сайта, оценки ИИ, ошибки.
- `No ads from: OLX` / `403` — сайт блокирует серверы GitHub. Можно запускать скрипт на своём компьютере через Планировщик задач Windows (`python main.py`, с переменными окружения из таблицы секретов).
- `Gemini request rejected (404)` — сменилось имя модели: задай переменную `GEMINI_MODEL` (актуальные имена — в AI Studio).
- `Gemini daily quota exhausted` — дневной лимит бесплатного ключа; уменьши `MAX_AI_PER_RUN`.
- Если ни один сайт не ответил, бот сам пришлёт ⚠️ в Telegram.
- GitHub отключает расписание в репозиториях без активности 60 дней; здесь бот сам коммитит `state/seen.json`, так что обычно это не грозит. Если всё же отключится — Actions → Enable workflow.

## Локальный запуск
```
pip install -r requirements.txt
set TELEGRAM_TOKEN=...  &  set TELEGRAM_CHAT_ID=...  &  set GEMINI_API_KEY=...
python main.py --dry-run     # показать находки в консоли, ничего не отправлять
python tests/test_parsers.py # офлайн-тесты парсеров
```
